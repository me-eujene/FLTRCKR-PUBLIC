# FLTRCKR: Flight Log & Records

Track personal travel records and flight statistics. Log longest flights, most-visited airports, favourite routes, and CO₂ emissions.

## About

FLTRCKR is a flight tracking app that helps you:
- Track personal travel records and flight statistics
- Log longest flights, most-visited airports, favourite routes, and CO₂ emissions
- Add flights easily: scan boarding pass barcodes, use natural language, or enter manually
- Add custom airports and aircraft types for complete flight logging flexibility
- Works offline

## Features

- 🗺️ Interactive map of all your destinations
- 📊 Flight statistics: distance, hours, countries visited, personal records
- 🌱 CO₂ emissions calculator
- 🤖 AI-powered flight search for past trips
- ⏱️ Countdown for upcoming flights
- ✈️ Add custom airports, locations and aircraft types
- 📤 Export and share your data
- 📱 Works offline
